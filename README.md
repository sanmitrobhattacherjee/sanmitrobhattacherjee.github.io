# Sanmitro Bhattacherjee — Research Portfolio

## Quick editing

Most changes can be made in **content.js**.

1. Open `content.js`.
2. Change the text between quotation marks.
3. Save the file.
4. Refresh `index.html` to preview the changes.

### CV
Put your latest CV in this same folder and name it:

`CV.pdf`

If you want another filename, change `hero.cv` in `content.js`.

### Links
Replace:
- `YOUR_EMAIL@example.com`
- `YOUR-LINKEDIN`
- `YOUR-GITHUB`

with your actual contact details.

## Free publishing

The easiest route is GitHub Pages:

1. Create a free GitHub account.
2. Create a new public repository.
3. Upload all files in this folder.
4. In the repository, open Settings → Pages.
5. Select deployment from the `main` branch.
6. GitHub will give you a public `github.io` link.

You can later connect a custom domain if you ever want one.
